# AutoCare & Mechanic Locator System

## 1. Project Overview & Methodology
* **Project Name:** AutoCare & Mechanic Locator System
* **Team Size:** 2 members
* **Development Methodology:** Scrum with XP (Extreme Programming) practices (Continuous Integration, Automated Testing, Task-driven Development)
* **Tech Stack:** Node.js, Express.js, Jest (Testing), GitHub Actions (CI/CD)

---

## 2. Backlog & User Stories
* **US1: Vehicle Maintenance Tracking** — Users can log vehicle details and view scheduled maintenance intervals.
* **US2: Nearby Mechanic Search** — Users can search for local mechanics based on location and service type.
* **US3: Mechanic Service Profile Management** — Mechanics can manage their service profiles, business hours, and service lists.
* **US4: CI/CD Pipeline & Initial Test Setup** — Continuous integration setup with automated unit test verification on every code push/PR (**Status: Completed**).
